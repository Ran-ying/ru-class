# RU-Class BYOK 公共服务架构约束（2026-10-16）

## 目标

RU-Class 提供课堂转写、文字稳定化、录音和未来翻译等软件功能，**不出售、不共享、不预置任何语音、图像或文字 AI API**。包括项目维护者本人在内，所有使用者必须自行填写每类 API 的地址、模型和 Token（允许用户自己选择本地推理服务）；没有配置语音 API 时不能开始云端识别，不尝试静默连接维护者的 ASR。

**系统级** `config.json` 只包含部署参数（listen.host/port、site.publicOrigin、站点层管理密钥等），不包含模型地址、厂商模型 ID、用户 Token。绝不能因旧 `ASR_BASE_URL`、`ASR_MODEL` 或 `ASR_API_KEY` 环境变量导致模型被隐式指定或阻止网页保存。

## v0.1.7 已实现的单用户内网过渡

- **不再提供默认 ASR URL / 模型 / 密钥**；示例配置和网页 API 地址占位文字无供应商预设。
- `config.json` 只读取部署参数；旧 `asr`/`models` 配置项不再生效。旧 `ASR_*` 环境变量对 RU-Class 主项目不起作用；独立 `ru-class-asr` 仍用自己的配置，其接口不会被 RU-Class 自动选择。
- 仅在 **内网单用户本机模式**，模型保存在 `data/local-models.json`（可通过 `RU_CLASS_LOCAL_MODELS_PATH` 更换）；只读时从此文件加载；新文件首次保存时创建目录并限制文件权限。不将模型配置写入服务器部署配置。
- 这一单用户文件**不是多用户解决方案**。仍然只有一个正在使用的 ASR adapter 和单个正在进行的课堂会话；不得宣称已经支持多人同时使用。
- 在 `site.publicOrigin` 已设置的情况下，服务器**不会加载单用户本地模型文件**，也不会把任何现有内网配置当成公网用户的默认 API。当前公网页面仍无法按用户保存模型，功能明确待实现。

## 公共多人服务实施门槛（必须在公网发布前完成）

1. **身份与用户隔离**：提供可靠的用户会话（例如注册/登录或独立匿名账户与恢复凭据）；每一次模型列表、保存、测试、ASR 会话、历史及未来录音的操作都绑定用户 ID，不能仅用共用的站点 Token 作为所有人的身份。不同用户之间的 API 信息、文字与录音互不可读写。
2. **用户凭据保管**：用户自带的 API Token 按用户加密存储，服务器端密钥在独立部署密钥源中；浏览器只收到 `keyConfigured` 等非敏感元数据。禁止把 Token 放到 URL、日志、WebSocket 广播或跨用户缓存。清除用户数据后须能删除相应密钥。
3. **ASR 会话隔离**：每个用户的录音 session 使用**该用户的**语音 API adapter 与模型，禁止全局 `directAdapter` 被某位用户保存操作修改而影响其他人的课堂；支持合理并发及每用户配额，避免一个账号耗尽服务器内存/连接。
4. **安全的 API 代理出口**：公网用户自由输入的 URL 属于不可信输入，不能直接让 VPS `fetch` 任意 URL。至少仅允许 HTTPS、做域名/IP 白名单或可靠的出站策略、拒绝 localhost/内网/元数据地址及 DNS 重绑定、限制重定向和请求体大小、超时、并发和调用频率；允许私有部署 ASR 的用户必须自己建立明确受信任的隧道或可安全访问的 HTTPS 端点。
5. **透明成本与隐私**：AI 提供商的 API 用量和费用由用户承担；RU-Class 不提供免费统一额度。标注第三方 API 会接收用户送出的音频/图像/文本，允许用户查看/撤销已保存凭据。免费公共网站仍需防滥用限额、审计及费用保护。
6. **浏览器和服务端配置 UX**：所有用户（包括维护者）打开模型设置时遵循完全相同的 BYOK 流程。语音未配置时给出明确提示，不显示虚构的预设模型。不允许公开用户查看或更改其他人的配置。

**验收前禁止直接把现有带单用户全局模型状态的服务当成可公开多人使用的 SaaS。** 当前 v0.1.7 仅适合作者的内网开发，下一阶段应先实现上述身份与每用户配置隔离，再考虑部署 HTTPS/WSS 站点。

## 现有内网迁移

1. 升级至 v0.1.7 后检查私有 `config.json` 和 `.env`：其中旧 `asr`/`models` 与 `ASR_*` 不再作为 RU-Class 提供者设置使用。**不要把它们留在公开可分享的文件中，也不要误删独立 `ru-class-asr` 自身的运行时密钥。**
2. 通过 RU-Class 网页“模型”页重新填写各 API，保存后会写入私有 `data/local-models.json`；此文件不应提交 Git。
3. 重新启动 RU-Class 后，确认地址/模型已从独立单用户文件恢复，并测试语音连接。不重新设置就尝试开始录音会提示未配置或尚未连接。
4. 此时仍不进行公网部署；待多用户认证和数据隔离完成后，另行迁移个人配置到自己的正式账户。
