# RU-Class 公共 BYOK 设计（v0.2.0）

**2026-10-16 最终确认：这是一个无需登录的公开网页，不是需要注册用户的 SaaS。** 之前关于“每用户服务器账户、服务器代管 API Key、加密用户数据库、每用户服务端 ASR Session / SSRF 代理”的设计**全部废弃**。详见 [浏览器直连权威架构](browser-direct-byok.md)。

每个访问者的 API 地址、模型、Token、课堂录音和转写历史仅存放在自己的浏览器 IndexedDB 中。网站提供静态 HTML、CSS 和 JS，用户自行向支持浏览器 CORS 的第三方 API 发起请求。包括维护者本人也不会得到默认模型或服务。第三方 API 如果不支持 CORS，RU-Class 不做代理，也不提供绕过方案；用户需要选择兼容 API。

**部署安全**：官方公共站点要有可信 HTTPS、严谨的 CSP、不注入未知第三方脚本、可复核的代码来源与缓存策略。浏览器中保存的密钥可被同源网页脚本读取，不能承诺它们获得硬件安全隔离。没有用户登录并不代表可以任意绕过浏览器和第三方 API 的安全要求。

**当前 v0.2.0 状态**：浏览器直接 ASR、IndexedDB 配置/文本/音频、原有文字稳定化已实现；图像推理、DeepSeek 翻译、词级时间戳和云端同步并未实现。用户必须自行配置支持 CORS 的 API 并在自己的设备上验证。旧 `data/local-models.json` 不再用于运行入口。
