# RU-Class v0.2 — 按日期选择课程、录音会话独立保存

## 正确的数据模型

- **课堂（classroom）**：`{id: UUID, key: 日期 + 标准化课程名称, date: YYYY-MM-DD, title}`。一个自然日同名课程只有一个课堂实体。课程名称会去掉首尾及重复空格，用 NFKC 和大小写无关的键判重；显示保留用户输入的课程名称。
- **录音会话（recording session）**：每次点击开始到点击停止产生一个独立 UUID，属于已选择的课堂。音频分块、每次 Whisper 原始窗口、证据完整性状态、对应文本都继续以**会话 UUID** 为键，避免多个会话的 `window_end_sample` / 音频分块索引 `0` 互相覆盖。
- **单节课堂可有多个录音片段**：同一课堂里再次点击开始，会追加一条新会话；不会覆盖前一次录音，也不把中间未录制的时间假装成连续声音。当前 v0.2 的 WAV 下载和播放**按会话单独进行**；不拼接音频或伪造跨片段绝对时间轴。
- **同一名称，不同日期**：允许两节课，例如 `2026-10-17 · 信息安全导论` 与 `2026-10-18 · 信息安全导论`。**同日同名**：不可再创建第二节课堂，但仍能在已有课堂中开始新的录音片段。
- 新建的课堂以 UUID 作内部 id，公开可比较的逻辑唯一键是日期 + 标准化名称。不会把课程名或日期写入 URL / 服务器帐号。

## 用户交互

1. 页面初始未选课堂，左上角显示「请先添加或选择课程」。右侧实时俄语字幕、历史区域灰化；录音按钮禁用。设置里仍可配置个人 ASR 接口。
2. 左上角的加号与选择器同行、右对齐；点击后弹出「添加课程」窗口，输入课程名称和日期，日期默认当前本地日。添加成功后自动选中刚创建的课堂；重复时提示回到已有列表，不会产生重复记录。
3. 从选择器切换课堂，加载该课堂以前的**多个录音会话**及原始字幕，在右侧历史列表显示每段的录制时间、持续时长、字幕；当前俄语区域显示最近一段已保存的结果。课程尚未选择时，不会自动开始转录。
4. 开始录音后禁用课程切换和加号，使用当前课堂 ID 创建新会话 UUID。录音结束后会话保存、加载历史，可在「设置 → 本地数据」分别播放或下载各段 WAV 和 ASR JSON。
5. 原有模型配置、右侧中文翻译占位、录音时延、转录算法等不变。

## 数据库兼容与旧数据

- 沿用同一个浏览器 Origin 和 IndexedDB 名称 `ru-class-local-v1`，schema **v3 → v4** 只添加 `classrooms` object store。
- 原有 `profiles`、`lessons`（其实是录音会话记录）、`audio`、`hypotheses`、`evidence` 不删除、不重写；不更改任何已保存的私人音频或 API 凭据。
- 旧会话没有 `classroomId`，新 UI 从其原有 `title` 和 `startedAt` 的**本地自然日**推导逻辑课堂键，把同日同名的记录显示在一个选择项下。只有分组视图发生变化，旧录音 ID、原始窗口导出仍保持原样。
- 如果已有同日同名的旧会话，新增同名课堂被拒绝，用户应直接选择对应旧分组；新录音可以加入该组。
- 这是单浏览器的私人数据，不做跨设备同步或身份系统。跨时区再次打开历史记录时，旧记录依据设备当时的本地日计算分组日期；未来如需跨时区稳定迁移可以对旧日期做显式一次性确认，但不能默默改写过去的录音。

## 验收边界

自动化覆盖同日同名判重、跨日同名、一个课堂多会话独立 ID、v1–v3 旧记录无损、选择前录音禁用以及添加弹窗。**真实 MacBook Safari v3→v4 升级、创建课堂、选择、录音、切换、历史加载仍需使用者实机检查。**

v0.2 仍有 30 分钟真实录音回放的未完成硬件验收。其他 Whisper 参数、PR #25 隔离、逐句时间戳、双语翻译不在这次调整范围内。
