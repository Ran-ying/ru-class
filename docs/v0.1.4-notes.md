# v0.1.4 · 设置标题栏和模型列表

## 设置界面

设置弹窗的顶部只有一行：左侧「设置」标题，中间「模型 / 访问」胶囊选项卡，右侧「×」关闭按钮。标题与关闭按钮采用与胶囊外边框相同的细边框和圆角。此行保持固定；只有下方设置内容滚动。窄屏时三部分仍处于同一行。

已移除模型面板顶部“各模型的 API 地址、模型名称、密钥独立保存……”的说明，不增加其他重复提示。

## 通过 API 查询模型

语音、图像、文字三套配置各自具有：

- API 地址、API Key（可留空复用同地址已保存的密钥）；
- 「获取模型列表」：由经过身份验证的 **主项目服务端** 请求当前填写地址的 `GET {baseUrl}/models`，不直接从浏览器访问第三方服务；
- 模型选择下拉框：使用该 API 返回的模型 `id` 填充，可选择后保存；
- 「手动输入模型 ID」作为下拉选项和回退方式，支持未实现模型列表接口的提供者；
- 独立「保存配置」与「测试连接」按钮，仍遵循 v0.1.3 的分离原则。

模型获取使用当前**尚未保存**的 API 地址和 Key，因此可先获取再选择、保存。请求不改变保存的配置、不重新启动 ASR、不把 API Key 回显到页面。仅在原地址完全相同时允许服务端复用已保存的 Key；变更地址需输入新 Key。改变 API 地址或密钥后会清除旧地址对应的下拉模型选项，防止把上一家提供者的模型误选进来；迟到的旧响应也不会覆盖新的选择。

后端仅接受正确的本机身份认证与 Origin；公网配置模式继续不开放模型设置编辑或模型枚举接口。请求仅使用 http/https，非 loopback 的明文 HTTP 不支持，不跟随重定向；每次有 10 秒超时、1 MiB 响应体及 5000 条记录上限，返回去重、排序后的合法模型 ID。

**能力边界：** 只能列出该提供者的 `/models` 接口**实际公布**的模型。并非所有服务实现 OpenAI 兼容 `/models`，也并非所有列出的模型都支持当前语音、图像或文字用途；列表成功不证明实际推理、额度或权限通过。无法列出时可以手动填入 ID，不会影响已有配置。
