# v0.6 逐句录音回放：设计与评估（2026-10-21）

## 目标（PROJECT_SPEC §8 / §11）

历史句子绑定完整录音中的 `[start_sample, end_sample)`，点击即回放；起止范围准确到可用水平；
不预切、不存储逐句音频文件。

## 数据流

| 环节 | 内容 |
|---|---|
| ASR 请求 | `direct-asr.js` 先请求 `verbose_json`；HTTP 400 时本次重试 `json`，此后整段录音保持 `json` |
| 原始证据 | `hypotheses` 记录新增可选 `segments[{start,end,text}]`（窗口内秒数）；文字与 `json` 完全相同；导出 `ru-class-asr-windows-v1` 的 `windows[]` 同样新增可选字段 |
| 词时间 | `TranscriptBuffer.update(..., segments)`：段内按字符偏移插值，换算为录音采样号，挂在词上；`state()` 输出 `stable_times` |
| 稳定片段 | `StableUnitJournal` 写入 `speechStartSample/EndSample`、`wordTimes`、`speechTimeSource:'whisper_segment_interpolated'`；无分段时仍为 `null` |
| 正式句子 | `sentenceTimes()`：一句对一个片段时直接取；否则按每句首词在原文中的位置切分，找不到时退回按词数比例 |
| 播放 | `recordingRangePcm()` 只读取覆盖范围的 3200 采样音频块；`speechBounds()` 修剪后生成 WAV `blob:` 播放 |

字幕过滤（`asr-hallucination.js`）同时作用于文字和分段，离线复核工具 `stable-source-audit.js`
使用与浏览器相同的输入，并核对片段时间。

## 为什么需要按录音修剪

在 M4 上实测：whisper.cpp 开启 VAD 时，**分段**时间会映射回原始录音（3.00–5.85 s 的语音返回
3.01–5.81 s），但**词**时间是去掉静音后的相对时间，而且是 `изуч` + `аем` 这样的子词碎片，因此只用分段。
分段有时跨过整段停顿，按字符插值后，边界会落在静音或相邻句里（第一轮测试最大偏差 3.2 s）。

`speech-bounds.js` 的规则（只依据录音本身，相邻句的估计只用于判断"这段语音属于谁"）：
- 噪声底取上下文 20% 分位，语音阈值 = 底 + 8%×(95% 分位 − 底)；没有明显对比时不修剪。
- 连续 ≥60 ms 才算语音，<0.3 s 的停顿不切开；在估计范围外 0.8 s 内搜索，只保留与估计范围重叠的语音段。
- 去掉首尾属于相邻句的语音段：完全落在相邻句估计内，或隔着 ≥0.5 s 停顿、且同时早于本句估计和上一句估计结尾（尾部对称处理）。
- 去掉首尾 <0.25 s、隔着 ≥0.8 s 停顿的孤立声音；至少保留一个语音段，不会把一句剪空。

## 评估

Mac mini M4，whisper.cpp small，temperatureInc 0.2，Silero VAD，DeepSeek `deepseek-flash`，
真实 Chrome（Xvfb 有头模式）以虚拟麦克风播放 macOS "Milena" 合成俄语。真实时间来自合成时的拼接位置。
"实际播放"包含首尾余量。

| 轮次 | 音频 | 语音覆盖率 | 播放内容为语音 | 完整句子完整覆盖 |
|---|---|---|---|---|
| v06a/b/c | 57 s，12 句，停顿 0.6–3 s | 100% | 91.5–91.7% | 31/31 |
| v06n/m | 同上 + 白噪声与 50 Hz 交流声（约 12 dB SNR） | 98.0–100% | 92.5–92.8% | 18/18 |
| hB（留出） | 新文本 43 s，语速 190，停顿 0.25–2.2 s | 100% | 89.5% | 8/8 |
| hBn（留出） | hB + 混响 + 低频噪声（约 6 dB SNR） | 99.7% | 91.2% | ASR 文字已严重出错，只能按时间评估 |

每轮所有可点击句子都在真实浏览器中点击，全部开始播放并自然结束。干净音频的完整句子起止误差多数在
0.12 s 以内；留出干净音频中有一句开头提前 1.23 s（多播放一点前文）。

## 局限

- 合成语音、单一说话人；真实课堂（远距离麦克风、多人、背景说话）尚未验收。
- 句间没有停顿的连续讲话，边界只能依赖 Whisper 估计和句首词定位，可能带入相邻句最多约 0.8 s。
- 时间是估计值，不是强制对齐；手动调整时间、课后强制对齐、导出逐句音频不在本版本内。
- 旧录音、或 ASR 端点不支持 `verbose_json` 时，句子没有时间，不可点击。
