# RU-Class v0.2 — 本地课程与完整录音回放

## 当前架构和实际范围

RU-Class 当前运行的是**浏览器直连 BYOK**，与旧版网关/Worker 架构不同。前端在 MacBook Safari 采集麦克风并写入本机 IndexedDB；Whisper API 可以独立部署在 Mac mini 上，个人 API Key 不经过 RU-Class 网站服务器。这个阶段的回放是**整节课的本地 WAV**，而不是 v0.6 将来要实现的逐句精确时间轴回放。

本次改动基于已经投入使用的 v0.2.2 基线：
- 课堂列表、录制时长、原始识别文本、独立窗口 JSON 和 WAV 下载已经存在；不重复实现。
- 新增 **设置 → 本地数据 → 每堂课「播放录音」**，将当前浏览器已保存的音频分块转换为 WAV Blob，只生成**一个** HTML5 `audio controls` 播放器。可以暂停、拖动播放位置和调整音量。
- 加载播放需先从 IndexedDB 组装 Blob；出于 Safari 的用户激活策略，**加载后需要用户在播放器再次点击播放**，不尝试自动播放。切换设置页、关闭设置、开始新录音、清空数据和关闭页面均会释放旧 Blob URL，避免不同课堂音频混用和内存长期占用。
- 使用原本私有的 `ru-class-local-v1` IndexedDB **v3** schema，无额外数据迁移。旧课堂只要保存了可完整组装的 PCM 分块，也能直接播放；旧课堂没有的 raw hypothesis 不会凭空补齐。
- WAV 组装会检查分块索引是否从 0 开始且连续、是否为完整的非空偶数字节 PCM16，防止悄悄导出一个有缺口但不报错的文件。
- 每条课堂可见记录展示**大约**多少 MiB 的音频 PCM；这是根据记录时长估算的容量，不代表本地完整性已实测。

## 30 分钟与限制

16kHz × 单声道 × PCM16 的未压缩音频体积：

- **每秒 32,000 字节**；
- **每 30 分钟 57,600,000 字节 ≈ 54.93 MiB**（外加 44 字节 WAV 头）；
- **每 90 分钟 172,800,000 字节 ≈ 164.79 MiB**，但 90 分钟是未来版本目标，本轮不宣称已验收。

本地浏览器保存长期录音还受 Safari 的 IndexedDB 容量、磁盘、后台冻结和内存限制影响。组装整段 WAV 需要读出全部 PCM 块并生成 Blob，长课程可能暂时占用超过一份音频体积的内存。**不能将 IndexedDB 当成唯一备份**；每节重要课堂结束后，下载完整 WAV 和 ASR-window JSON 至可靠文件位置。

自动化回归包含：
- 多分块合并顺序、WAV 采样率/通道/位深及实际 PCM 字节；
- 空音频、缺分块、索引重复、坏字节块不应生成伪完整 WAV；
- **30 分钟 57.6MB 合成音频 Blob** 的长度、WAV 头和前/后片段；
- 一台浏览器同一时间只存在一个本地播放器、ObjectURL 生命周期回收；
- 现有课程、配置、旧格式窗口迁移与录音数据存续的旧测试继续运行。

**这些是 Node/CI 的模拟测试，不是 30 分钟 MacBook Safari 实机麦克风运行**。因此版本功能完成不等于 v0.2 30 分钟硬件/容量验收通过。

## MacBook Safari 使用与正式验收

1. 在现有 MacBook `ru-class` 仓库更新代码。沿用原来的网站地址和 Safari 浏览器资料目录，避免误以为更换 Origin 后旧 IndexedDB 记录丢失。
2. 在 Safari 开启网站的「设置 → 本地数据」，选一份旧课程，点击「播放录音」，在出现的音频控件点击播放，试着暂停、拖动进度、切到另一节课；确认旧课 WAV 下载仍正常。
3. 录制一个新短课程，停止后刷新页面，确认名称、时长、字幕、完整性状态和录音都还在，WAV 与 JSON 能各自下载。
4. 如需严格 v0.2 完成验收，在有足够本地空间的 MacBook Safari 用**非重要、同意测试的录音**进行连续 30 分钟前台录制，停止后下载 WAV，核对媒体时长、预期 PCM 大小和实际可播放的起点/中部/末尾；记录窗口数量、失败提示、刷新再载入的结果。此步骤**尚未由 GitHub CI 或助手完成**。
5. 继续把 Safari 旧版 IndexedDB 升级、双标签页升级/空间不足异常测试留在 Issue #28；不要误报为通过。

## 不在本轮范围

不加入课堂逐句精确时间戳/逐句跳转回放、OPFS 重写、断点自动恢复、断线音频补识别、完整 ZIP 跨浏览器迁移、DeepSeek 断句或中文翻译（分别属于未来版本）。不更改 Whisper 及 `TranscriptBuffer`，不启用 Draft PR #25 的删除式启发规则。所有私人录音留在使用者浏览器/自有下载目录。
