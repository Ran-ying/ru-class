# v0.1.3 · 录音停止显示、俄语对齐和模型设置

## 停止录音后

录音正常停止时不在 RU 区域显示“已停止 · 尾部识别完成”或“等待语音识别 API”等连接状态文案。已识别俄语和已录制时长留在页面，工具条恢复“开始录音”；错误时仍显示对应错误信息。下次开始录音才清空本次文字。

## 稳定化加强

独立 8 秒滑动音频窗口不变。服务器积累 **append-only 稳定文字 + 可改写临时尾部**，且新窗口必须和**紧邻的上一次原始 Whisper 假设**存在可信词串重叠，才允许把新假设与旧文字对齐；不能直接拿数分钟前稳定文字中的高频词作为锚点。如果新一句恰好再次出现“методы защиты информации”等旧术语，须先等待连续两个相邻新假设确认，而非删除该新句或改写旧句。

在确认旧稳定前缀仍然相等之后才接受候选合并；识别改写的格变化（例如 “защита”→“защиты”）可落在临时尾部中。遇单次空识别保持尾部，持续空识别可结算尾部。已确认稳定前缀不会被普通后续推理改写。

限制：当前 ASR API 仅提供整段窗口俄语，不提供词级对齐数据，重复一句完全相同的话、极端长静音和频繁纠错仍无法达到绝对无漏字或零重复；这一点需要后续更精细的 ASR 时间对齐和 v0.2 原始录音留存支持。v0.1.3 不包括持久录音和 DeepSeek 句子消费。

## 模型设置

设置对话框顶部是胶囊式 **模型 / 访问** 选项卡。“模型”内提供三块独立表单：

- **语音**：当前实际使用的独立 OpenAI 兼容 ASR；更改配置后可单独测试连接，成功才标记当前已保存语音模型可用。
- **图像**：为未来课堂图片处理预留；现在仅可保存和测试模型列表接口，不调用图像推理。
- **文字**：为未来 DeepSeek 断句和翻译预留；现在仅可保存和测试模型列表接口，不调用文本生成。

每块表单独立编辑 API 地址（含 `/v1` 等前缀）、模型 ID 和 API Key。**保存配置**只验证格式并独立、原子写入服务器的 Git 忽略文件 `config.json`，不会自动联网；**测试连接**单独访问目标提供者 `GET {baseUrl}/models`，用 Bearer Key 验证 API、模型列表及目标模型是否可见，不写磁盘，也不表示音频/图像/文字的推理实际成功。不是所有厂商都提供这个兼容接口；不兼容该接口的提供者会显示检测失败，未来按需扩充 adapter。

密钥只在服务端 `config.json` 中，文件写入为 0600，浏览器读取配置时仅得到 `keyConfigured` 布尔值，留空密钥在相同地址时保留旧密钥，**改换 API 地址必须重新提供密钥**。三种模型配置相互独立，可单独保存，不影响其他两组及服务器监听端口等设置。仍支持旧 `asr` JSON 结构；新的 `models.speech` 优先于旧的 `asr`，`ASR_*` 环境变量仍优先于 JSON；被环境变量覆盖时禁止在网页覆盖语音模型，避免用户以为保存成功却不生效。

**内网本机模式**才允许网页修改模型设置；公网反代模式下为避免泄露或滥用服务端配置，仍只能由服务器管理员编辑私有 `config.json`。单独的“访问”选项卡用于公网站点访问令牌；本机模式不需要手动输入令牌。

## 开发与测试

```sh
npm ci
ASR_REPO=../ru-class-asr npm test
npm run typecheck
npm run build
```

自动化测试涵盖现有浏览器工作流、语音/图像/文字模型配置独立保存、密钥不返回客户端、测试接口和模型验证、静音、连续俄语、相同术语在两句话中的重复以及变格纠错。CI 通过表示在模拟环境完成代码回归，不代表已在真实 Mac/M4/iPad 麦克风环境实测。

本次仍**没有进行公网部署、DeepSeek 接入、图片推理或课堂录音持久化**。
