# P1 C1 #30: private candidate attribution, no automatic recovery

**Status: DRAFT RESEARCH.** This tool narrows the question **"what
was lost versus merely moved into later subtitles?"** without
inventing a spoken transcript or changing a running RU-Class session.

## Evidence motivating this experiment

The original C1 cache has 121 windows and a suspected overwritten
25-word hypothesis at #30. A real, independent Alibaba Cloud Beijing
Qwen3-ASR test (6/6 successful across C1/C2 focus/context cases)
showed six contiguous words and approximately 0.651 normalized
lexical similarity with that discarded hypothesis. Later Whisper
window #32 shared seven contiguous words with the old candidate.
But it has never been proven from human listening that those words
were actually spoken and absent from final subtitles. C1 #120
provides a strong **counterexample to auto-restoration**: replacing
a short three-word draft with an independent-model-supported
15-word final window is likely a healthy correction.

The previous experimental PR #22 successfully isolated C2 #76's
extreme repetition in a **separate private counterfactual**, without
changing C1 or the production transcript. The current experiment is
**separate from PR #22** and answers a different question.

## Inputs / actual algorithm

`scripts/audit-candidate-attribution.mjs` reads:
- The original, locally converted C1/C2 Whisper window JSON
  (texts plus *audio window* start/end **sample coordinates**).
- The **previously obtained** private `cross-asr-private.json`
  generated by the official Beijing Qwen3-ASR script.

Nothing contacts Alibaba Cloud or any other network endpoint.
The temporary API key has been **disabled**; none is needed.

The analyzer replays the **unchanged** `TranscriptBuffer`, only
admitting a target index where its real `unanchoredReplacementCount`
increments by one, and records the actual displaced candidate
**in process memory only**.

For that candidate it independently compares normalized **contiguous
three-or-more-word runs** with (a) Qwen 8-second focus, (b) Qwen
12/10-second context, (c) each of the next *two* Whisper windows
**separately**, and (d) the final visible subtitle. A contiguous match
may never cross an artificial concatenation of two distinct windows.
It reports only matching-token counts, best-run lengths, window
indices and input sample bounds. The Qwen JSON focus audio sample
coordinates and original Whisper focus text **must exactly match**
the supplied cache; otherwise it refuses to produce a report.

`modelAndLaterSupportedWords` means at least two hypotheses support
the *same candidate token positions*. Because two Qwen context
outputs come from one model family and every ASR can err, this is
not a true-word count. Similarly, `modelAndLaterSupportedButNotLexicallyCoveredWords`
is the subset lacking an exact three-word run somewhere in the final
subtitle, **not a measured real omission**. Conversely, a matching
phrase somewhere in final text may belong to an earlier repeated
utterance: even positive final lexical coverage cannot establish a
correct temporal assignment.

**Critical time limitation:** source sample bounds label whole
8-second ASR windows. Qwen does **not** provide verified per-word
timestamps in the saved report. Shared audio-window time does not
identify the occurrence of any particular word. Therefore this tool
**does not insert, restore, freeze or delete any captions**. Every
output is `REVIEW_ONLY_NO_AUTOMATIC_RESTORATION` with explicit null
spoken-omission and true-recovery counts. Genuine identical phrases
uttered twice remain a known unfixed lexical-alignment edge case.

## Required admission before any future recovery

A partial recovery proposal must distinguish:

1. Independent ASR support versus the **same occurrence** in audio.
2. Already visible downstream phrases versus truly missing speech,
   including duplicated material in earlier portions of the transcript.
3. Normal final correction (#120), spurious Whisper loop (#76/#77),
   and two genuine identical utterances in overlapping windows.
4. Append-only stable text and 45 known repeated-sample regressions;
   all 227 stop prefixes; C1 121/C2 106 whole-cache comparisons.

If Qwen/Whisper evidence suggests a gap but **word identity and time
remain unverified**, label it as a review candidate. The next
engineering step is an *independently source-verified
word-timestamp/speech-region attribution*, not silent reinsertion.
