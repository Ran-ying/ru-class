# v0.1.6 · 模型选择图标与 Token 输入简化

## 交互变化

三个设置卡（语音、图像、文字）统一如下：

1. 开始只展示 **API 地址** 和 **获取可用模型** 按钮。
2. 获取成功后，整个“获取可用模型”按钮及其旁边的说明文字**消失**；取而代之的是：
   - 有模型时：下拉选择框（用户自行选定，不允许手动填写），右边为刷新图标；
   - 确定无模型或 API 不提供 `/models` 时：手动输入模型 ID；
   - 同时直接显示 **API Token 密码输入框**，不再需要点击“填写 Token”按钮。
3. 选好模型并填写 Token（或已保存同一 API 地址的 Token）后，显示独立的 **保存配置 / 测试连接** 按钮。获取列表本身不会保存配置或触发测试。
4. 如果 `/models` 返回 401/403，则仍保留最初的获取按钮用于重试，同时直接显示 Token 输入框，待补填 Token 再查询。
5. 修改 API 地址时重置已查询的选项、Token 和操作按钮；网络延迟返回的旧地址列表无法恢复这些状态。下拉框右侧刷新时尽可能保留仍然有效的选中模型。

## 视觉调整

下拉框原生的小三角替换为可控尺寸的 SVG chevron，与刷新按钮中的 SVG 使用相同的 20 × 20 px 画布和描边，三角距离输入框右边界内缩 13px；刷新按钮仍维持适当点击热区。不要把 SVG 图标大小与整个按钮的点击区域混淆。

## 范围及验证

此次不修改 ASR、录音或后续 DeepSeek 工作，只调整现有设置 UI。通过自动化测试确认模型获取后隐藏原按钮/提示、Token 同时显示、手动回退、401 特殊流程、修改地址后重置以及下拉和刷新 SVG 的共同尺寸；**真实 Safari 的视觉验收仍需在用户内网设备进行**。未进行内网或公网部署。
