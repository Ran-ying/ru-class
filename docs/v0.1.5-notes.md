# v0.1.5 · 分步模型配置交互

## 语音 / 图像 / 文字的共同流程

1. 初始仅展示 **API 地址** 输入框，以及下方的「**获取可用模型**」按钮。
2. 点击按钮时由 RU-Class 后端访问该地址的 `GET /models`，不需要先保存配置。
   - 如果返回了一个或多个合法模型 ID：出现 **仅包含服务器实际返回模型的下拉框**，必须主动选择一项，不允许手动输入，也不预选第一个。
   - 如果返回空列表，或明确不支持模型列表接口（404/405/501、无列表结构）：显示手动 **模型 ID 输入框**，不展示选择框。
   - 如果接口返回 **401/403**：这是鉴权要求，**不是没有模型**。提前显示「填写 Token」，填写后再次点击「获取可用模型」，随后才能选择模型。
   - 网络超时、其他 API 错误则显示失败并允许重试，不误把一次暂时失败当作确定无可用模型。
3. 选定模型（或填写手动模型 ID）后，出现「**填写 Token**」按钮；点击后展开 Token 输入框。新地址必须输入 Token；同一地址已有保存的 Token 时可留空复用服务器端凭据。
4. Token 已输入（或已保存并可复用），才显示 **「保存配置」和「测试连接」** 两个独立按钮；保存与测试不相互触发。
5. 发现到模型时，**模型下拉框右侧**有「↻」刷新按钮。刷新从当前地址重新获取列表，如选中的模型仍存在则保留，否则要求重新选择。
6. **任何 API 地址的改动都重置后续所有步骤**，包括已列出的模型、待选模型、Token 草稿和两个操作按钮。过期异步响应不得恢复旧地址的模型。

## 技术与安全约束

- 模型发现由身份验证后的本地 RU-Class 网关代为发起；**不向浏览器返回服务器端保存的 API Key**，不写 `config.json`，不更改正在使用的识别器。
- 第一次匿名查询对无需鉴权的 `/models` 可用；若有已保存的同地址 Token 可自动在服务端复用；**不同地址绝不可复用旧密钥**。需 Token 的 API 会明确提示填写后重试。
- 语音、图像和文字三类彼此独立；公网反代模式依然禁止在浏览器管理后端模型地址、Key 或列举模型。
- 下拉列表只表示供应商公布了模型 ID，不代表模型能执行目标模态、账号额度有效或推理已经测试。厂商的 `/models` 接口不兼容时使用手动模型名；保存流程仍要求 Token。
- 文本、图像的实际推理和 DeepSeek 调用不在 v0.1.5 范围内。

## 验证

```sh
ASR_REPO=../ru-class-asr npm test
npm run typecheck
npm run build
```

自动化验证覆盖匿名可列出模型、需 Token 才可列出模型、成功列表只允许选择、空列表的手动输入、选择后 Token 步骤、Token 前不显示保存/测试、同地址复用凭据、刷新保留已选项、变更 URL 全流程重置。还需在作者自己的 Mac/iPad 上实测最终弹窗表现。

本版不操作内网部署，也不进行公网反向代理部署；独立 `ru-class-asr` 无运行时变更。
